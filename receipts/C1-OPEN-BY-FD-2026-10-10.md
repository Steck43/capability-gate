## Boundary

`open_authorized_read` opens a regular file once with `O_NOFOLLOW`, resolves
the opened object through Linux `/proc/self/fd`, asks the gate about that
object, and returns the same descriptor for the host action. An attacker can
replace the request name after the decision without redirecting the read.
Unsupported platforms deny instead of reverting to a name check followed by a
second open.

The pinned Hermes host still resolves `path` in `read_file_tool` and later
passes the name to `ShellFileOperations.read_file`. It does not consume this
primitive. This receipt proves the gate-roof primitive and regression, not
live Hermes wiring.
